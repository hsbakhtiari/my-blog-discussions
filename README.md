# Blog Comments Repository

This public repository is used solely to store **GitHub Discussions** for blog post comments on [hosseinbakhtiari.com](https://hosseinbakhtiari.com).

## Why this repository exists

The main blog source code is kept private. To enable a commenting system on public blog posts using [Giscus](https://giscus.app), this repository serves as the public **discussion backend**.

Each blog post maps to a GitHub Discussion thread via Giscus, enabling readers to engage in conversations directly on the post.

## How it works

- Comments are powered by [Giscus](https://github.com/giscus/giscus), which uses GitHub Discussions.
- Each post's comment thread is matched by its URL/path.
- All discussions happen under the `General` (or `Comments`) category.

## Notes

- This repository contains no actual source code or content.
- Only Discussions are used.
- If you're looking for the blog itself, visit: [hosseinbakhtiari.com](https://hosseinbakhtiari.com)
